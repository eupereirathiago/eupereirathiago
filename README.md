### 🚀 O que eu faço

- 🎯 **Diagnóstico de Necessidades:** Entendo os gargalos e as rotinas do usuário antes de planejar qualquer funcionalidade.
- ⚡ **Desenvolvimento Acelerado por IA:** Utilizo **Google AI Studio**, **Claude** e **ChatGPT** para prototipar telas, validar regras de negócio e estruturar aplicações completas com agilidade.
- ☁️ **Back-end & Dados na Nuvem:** Estruturo a persistência e a lógica de dados usando soluções nativas e gerenciadas — escolhendo entre **Firebase / Google Cloud** para agilidade e ecossistema integrado, ou **Supabase** para projetos que exigem escalabilidade e modelagem relacional.
- 📱 **Foco em Usabilidade:** Crio interfaces diretas e intuitivas, eliminando complexidade e burocracia para o usuário final.
